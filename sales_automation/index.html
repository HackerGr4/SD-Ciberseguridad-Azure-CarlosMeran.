Observación de seguridad mediante reglas

Una demostración educativa con datos simulados e informes HTML y JSON para explicar coincidencias y límites de cobertura.

Prototipo experimental. No es un servicio de seguridad validado.

Conocer el alcance de la demo

Reglas de red

Registra coincidencias con las reglas IP y CIDR configuradas. Una coincidencia de política requiere revisión humana; no confirma malware ni robo de datos.

Indicios para revisar

Compara patrones de texto y nombres de procesos con listas configuradas. Estos indicios pueden aparecer en software legítimo. No incluye firmas de malware verificadas.

Informes HTML y JSON

Documenta coincidencias, reglas y errores registrados. Los informes no certifican limpieza, seguridad ni cumplimiento normativo. No genera PDF.

Qué muestra la demostración

demo.py utiliza procesos, direcciones y archivos ficticios, y produce informes identificados como DATOS SIMULADOS. No inspecciona los procesos o conexiones del equipo ni ejecuta remediaciones reales.

La observación fuera de la demo tiene cobertura parcial según los permisos y la plataforma. No es monitoreo continuo ni una validación de Azure o infraestructura remota. No encontrar coincidencias no demuestra que un equipo esté limpio.

Qué falta para un servicio de seguridad validado

Se necesitan indicadores verificables y mantenidos, métricas de detección y errores, pruebas de integración autorizadas y procedimientos operativos validados. Las pruebas actuales con datos simulados no acreditan eficacia frente a malware real ni remediación profesional.

La presentación se limita al funcionamiento educativo del prototipo. No ofrece limpieza de equipos, certificación de cumplimiento, tiempos garantizados o resultados económicos.
